# DPIA screening record

Processing: current Axis One public website and website-originated enquiries

Screening date: 30 August 2026

Status: technically reviewed; pending named controller approval

## Current scope

- Static public website delivered through Cloudflare Pages.
- Routine delivery and security request data.
- Decision Brief and enquiry fields prepared in the browser and sent only through the visitor's chosen email client.
- No backend form database, profiling, behavioural advertising, special-category data request, large-scale monitoring or solely automated significant decision.
- Cloudflare Web Analytics disabled.

## High-risk indicators

| Indicator | Current finding |
| --- | --- |
| Systematic evaluation or profiling | No |
| Solely automated decisions with legal or similarly significant effects | No |
| Systematic monitoring | No beyond routine delivery/security controls |
| Large-scale special-category or criminal-offence data | No |
| Large-scale processing of vulnerable people | No |
| Matching or combining data sets | No |
| Innovative technology creating material privacy risk | No in the current website flow |
| Processing preventing a person exercising a right or using a service | No |

## Screening conclusion

The current public website processing is not likely to result in a high risk to people's rights and freedoms, so a full DPIA is not required on the present facts. This conclusion depends on the controls and scope described above.

## Mandatory re-screen triggers

Complete a new screen before introducing:

- server-side forms, CRM synchronisation or persistent visitor accounts;
- analytics, fingerprinting, advertising or cross-site identifiers;
- AI analysis of free text or automated scoring;
- special-category, criminal-offence, employee or vulnerable-person data;
- data-set matching, large-scale monitoring or significant automated decisions;
- a new provider, transfer mechanism or purpose that materially changes risk.

If a trigger creates likely high risk, complete and approve a full DPIA before processing begins.
