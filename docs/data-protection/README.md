# AX1 data-protection operating pack

Owner: AX1 Structura Ltd

Controller contact: info@ax1.capital

Effective date: 30 August 2026

Review cycle: at least annually and before any material change to processing

## Purpose

This pack supports the public Privacy and Cookie Policies with the internal records and procedures needed to operate them. It covers the current public Axis One website and enquiries initiated from it. It is a living operational record, not a substitute for legal advice on a new product, market or processing activity.

## Current verified technical position

- Decision Brief and enquiry inputs remain in the visitor's browser until the visitor chooses to send an email.
- The website does not submit forms to an AX1 database or application backend.
- Cloudflare Web Analytics is disabled for the Pages project and the `ax1.capital` zone.
- No advertising pixels, behavioural profiling or non-essential browser storage are authorised.
- Any proposal to add analytics, a CRM form, automated decision-making, AI processing, special-category data or persistent browser identifiers requires a new privacy review before activation.

These controls were verified against the website source and release configuration on 31 August 2026. They do not replace the controller approvals and provider-contract evidence listed below.
